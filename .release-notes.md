## 🚀 What's New in v0.0.3

### Highlights
This release is a security-focused patch that hardens the greeting-service container image by remediating known CVEs in bundled npm dependencies. No functional changes have been made — the service behaviour remains identical to v0.0.2. CI pipeline reliability has also been improved with several tooling fixes.

### 🔒 Security
- Pinned `brace-expansion` to `>=5.0.8` via npm `overrides` to remediate a known vulnerability; a `.trivyignore` file has been added for accepted/suppressed findings.
- Upgraded `npm` in the Docker runtime stage to resolve bundled CVEs affecting `tar`, `brace-expansion`, and `sigstore`.
- Container image scanning with Trivy is now active in CI; scan results are reported on every build without blocking the pipeline.

### 🐛 Bug Fixes
- Fixed Trivy container scan `image-ref` to correctly target the `:main` tag during CI runs.
